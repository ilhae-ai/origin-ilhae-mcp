# 설치 가이드

> 대상: Origin을 쓰는 연구실·기업 사용자(개발 경험이 없어도 따라 할 수 있게 썼습니다)
> 소요 시간: 약 15분

## 준비물

- Windows 10 또는 11
- Origin/OriginPro **2021 이상** (라이선스 활성화된 상태)
- Claude Desktop 또는 Claude Code
- 인터넷 연결 (처음 설치할 때만)

## 1단계. uv 설치 (Python 실행 도구)

PowerShell을 열고(시작 메뉴에서 "PowerShell" 검색) 아래 한 줄을 붙여 넣습니다.

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

설치가 끝나면 PowerShell을 닫았다가 다시 엽니다.

## 2단계. origin-ilhae-mcp 설치

```powershell
uv tool install "origin-ilhae-mcp[windows,encoding]"
```

> 최신 개발 버전을 쓰려면 `uv tool install "origin-ilhae-mcp[windows,encoding] @ git+https://github.com/ilhae-ai/origin-ilhae-mcp"`를 실행합니다.

## 3단계. 브리지 설치와 Claude 등록

측정 데이터가 있는 폴더를 `--root`로 알려줍니다. 여러 개면 여러 번 씁니다.
**여기 적은 폴더 안의 파일만** Claude가 읽고 쓸 수 있습니다.

```powershell
origin-ilhae-mcp install --claude-desktop --root "$HOME\Documents" --root "D:\측정데이터"
```

화면에 다음과 같은 안내가 나옵니다.

```
[2/3] Origin 스크립트 창(창 > 스크립트 창)에 아래 한 줄을 붙여 넣고 Enter:
      run -pyf "C:\Users\...\origin-ilhae\ilhae_start.py";
```

Claude Code를 쓴다면 `origin-ilhae-mcp config`가 보여주는 `claude mcp add ...` 명령을 실행합니다.

## 4단계. Origin에서 브리지 시작

1. Origin을 켭니다.
2. 메뉴에서 **창(Window) → 스크립트 창(Script Window)** 을 엽니다.
3. 3단계에서 안내받은 `run -pyf "...ilhae_start.py";` 줄을 붙여 넣고 Enter를 누릅니다.
4. `[origin-ilhae] 브리지 시작: 127.0.0.1:47021`이 나오면 성공입니다.

> Origin을 다시 켤 때마다 4단계를 반복합니다. 브리지를 켜지 않아도 COM 방식으로 자동 연결을 시도하지만, 브리지가 더 안정적입니다.

## 5단계. 점검

```powershell
origin-ilhae-mcp doctor
```

| 결과 | 의미 |
|---|---|
| `✓ Origin 2025b ...` | 연결 성공 |
| `✓ column_long_name` 등 | 한글 처리 정상 |
| `✗ export_korean_path` | 한글 폴더에 그림을 바로 저장하지 못합니다. 자동으로 영문 임시 폴더를 거쳐 저장하므로 사용에는 문제없습니다 |
| `✗ Origin 연결 실패` | Origin이 켜져 있는지, 4단계를 했는지 확인 |

## 6단계. Claude Desktop 재시작 후 사용

Claude에게 이렇게 말해 보세요.

> D:\측정데이터\다이오드.csv 불러와서 I-V 분석하고 로그 그래프로 보여줘

## 문제 해결

| 증상 | 해결 |
|---|---|
| "허용된 폴더 밖의 경로" | 3단계를 `--root "그 폴더"`로 다시 실행 |
| "작업이 60초 안에 끝나지 않았습니다" | Origin 화면에 떠 있는 대화상자를 닫고 다시 요청 |
| 그래프 한글이 네모로 나옴 | "그래프 글꼴을 맑은 고딕으로 바꿔줘" |
| CSV 글자가 깨짐 | "인코딩을 cp949로 지정해서 다시 불러와줘" |
| 브리지 토큰 오류 | Origin에서 브리지를 다시 시작하고 Claude를 재시작 |

## 제거

```powershell
uv tool uninstall origin-ilhae-mcp
```

브리지 파일은 `문서\OriginLab\User Files\origin-ilhae` 폴더에 있습니다. 필요 없으면 직접 지우면 됩니다.
