# 툴 목록 (v0.1.0, 기본 29개 + 선택 2개)

`ILHAE_TOOLSETS`로 묶음을 고릅니다. 기본값은 `core,korea,physics`입니다.
상태를 바꾸는 툴은 `verify.status`로 결과를 판정합니다.

| 값 | 의미 |
|---|---|
| `verified` | 요청한 값이 그대로 반영됨 |
| `mismatch` | 요청과 다른 값이 반영됨 |
| `partial` | 일부 항목을 확인하지 못함 |
| `unverified` | 다시 읽지 못함 |

## physics (8개)

모든 툴은 `path`(측정 파일)와 `book`(Origin 워크북) 중 하나로 데이터를 받습니다.
열을 생략하면 열 역할(voltage, current 등)로 자동 선택하고, 단위는 SI로 환산합니다.

| 툴 | 계산 | 결과 그래프 |
|---|---|---|
| `iv_diode_analyze` | 이상계수 n·포화전류 I0(반로그법), 직렬저항 Rs(Cheung 법) | \|I\|(로그) - V |
| `transistor_analyze` | Vth(접선 외삽, linear는 Vd/2 보정), gm, SS(mV/dec), on/off 비, 이동도(선택), n형·p형 판별 | \|Id\|(로그) + √\|Id\| 또는 gm(이중 Y축) |
| `cv_mott_schottky` | 평탄대전압 Vfb, 도핑 농도 N(cm⁻³), n형·p형(직선 구간 자동 선택 또는 지정) | 1/C² - V |
| `spectrum_fft` | 단측 진폭 스펙트럼, 지배 주파수, 샘플링 간격 균일성 경고 | 진폭 - 주파수 |
| `spectrum_peaks_fit` | 다중 피크(가우시안·로렌츠·보이트 + 기준선): 중심, FWHM, 면적, R² | 측정 + 피팅 |
| `signal_filter` | Butterworth 저역·고역·대역 필터(위상 지연 없음), Savitzky-Golay | 원신호 + 필터 |
| `bode_plot` | 이득(dB, 또는 vin·vout으로 계산), -3 dB 차단 주파수, 위상 | 이득(로그 주파수) + 위상(이중 Y축) |
| `arrhenius_fit` | 활성화 에너지 Ea(eV) | ln k - 1000/T |
